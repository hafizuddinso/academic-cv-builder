# Contributing

Thanks for helping make academic CVs easier to create. Bug reports, documentation improvements and accessibility fixes are welcome.

1. Open an issue describing the proposed change.
2. Fork the repository and make changes on a descriptive branch.
3. Run `npm install`, `npm run typecheck` and `npm run build` locally.
4. Open a pull request with screenshots if you changed the interface.

Please do not submit personal CV details, email addresses, real tokens, or screenshots containing private information. AI rewrites must avoid inventing qualifications or publication details.
