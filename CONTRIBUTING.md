# Contributing

Academic CV Studio is a free no-login editor for PhD applicants, researchers and scholarship candidates.

1. Open an issue with the problem or improvement.
2. Fork the repository and work on a topic branch.
3. Run `npm install`, `npm run typecheck` and `npm run build` before opening a PR.
4. Include screenshots for interface changes, using **fictional sample CVs only**.

Do not add login requirements, back-end credentials, actual applicant details or unpublished research data to examples. Offline writing suggestions must never invent qualifications or publications.
